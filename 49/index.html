복소수 보충 학습

복소수의 나눗셈과 켤레복소수의 성질을 활용하여 식을 효율적으로 변형하는 방법을 확인합니다.

\(\mathrm{6}\)번 보충

출제 의도
복소수의 나눗셈에서 각 분수를 개별적으로 계산하는 방법뿐 아니라, 두 분수를 통분하여 하나의 식으로 정리하는 과정을 통해 복소수의 사칙연산을 종합적으로 활용할 수 있는지 확인하고자 한다. 특히 통분 과정에서 분모와 분자를 정확히 구성하고, 분모에 나타나는 복소수의 곱을 실수로 정리하는 과정에서 켤레복소수의 성질을 활용하도록 하여 계산의 구조를 이해하는 능력을 평가한다. 또한 단순한 기계적 계산보다 식 전체를 효율적으로 변형하여 계산하는 전략을 익히도록 하는 데 목적이 있다.

문제

두 복소수 \[ \alpha=1+2i,\qquad \beta=2-i \] 에 대하여 \[ \frac{\alpha}{\beta}+\frac{\beta}{\alpha} \] 의 값을 구하시오.

정답 \[ \boxed{0} \]

풀이

\[ \alpha^2=(1+2i)^2=1+4i-4=-3+4i \] \[ \beta^2=(2-i)^2=4-4i-1=3-4i \]
이므로 \[ \frac{\alpha}{\beta}+\frac{\beta}{\alpha} = \frac{\alpha^2+\beta^2}{\alpha\beta} = \frac{0}{\alpha\beta} = \boxed{0} \]

\(\mathrm{7}\)번 보충

출제 의도
교과서의 복소수 계산 문제를 역방향 추론 형태로 확장하였다. 복소수를 직접 구하지 않고 복소수와 켤레복소수의 합과 곱을 이용하여 제곱의 합을 계산하도록 하여, 식의 변형과 켤레복소수의 성질을 연결하는 능력을 평가한다.

문제

복소수 \(z\)가 \[ z+\overline{z}=6,\qquad z\overline{z}=13 \] 을 만족시킬 때, \[ z^2+\overline{z}^{\,2} \] 의 값을 구하시오.

정답 \[ \boxed{10} \]

풀이

\[ z^2+\overline{z}^{\,2} = (z+\overline{z})^2-2z\overline{z} \] \[ = 6^2-2\cdot 13 = 36-26 = \boxed{10} \]
